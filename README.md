# rust-web-store-rahmananin 
Задание "Интернет Магазин э" - реализация на Rust

## Используемые библиотеки:
**axum** - Для работы с сервером 

**askama** - Работа с html-шаблонами + вспомогательная библиотека askama_web для интеграции с **axum**

**tokio** - Асинхронный рантайм. В стандартной библиотеке Rust нет асинхронности как в других языках вместо этого нужно подключить
одну из готовых библиотек и самая популярная из них - **tokio**

**sqlx** - Работа с SQL базами данных (MySQL, PostgreSQL, SQLite)

**serde** - Серилизатор. Позволяет переводить обычную структуру в другой текстовый формат, к примеру - `JSON`

**tracing** & **tracing-subscriber** - Удобные инструменты для логирования, позволяют писать сообщения в консоль
разных уровней (info, error, warn и т.д.)

## Структура проекта
`/src` -  Основной rust-код

`/static` - Статические файлы (css, js, медиа файлы)

`/templates` - html-шаблоны
> [!NOTE]
> ### Как работают шаблоны?
> В rust-коде мы создаем структуру-обертку которая будет содержать переменные необходимые в шаблоне
> (весь дальнейший код будет находится в одном файле)
> ```rust
> #[derive(Template]
> #[template(path = "index.html")]
> pub struct HomePage {
>   pub hello_message: String
> }
> ```
> Синтаксисом `#[derive(Template)]` (где `Template` это макрос из библиотеки **askama** )
> мы помечаем нашу структуру как html-шаблон
>
> Привязываем к ней конкретный html-файл через аттрибут
> `#[template(path = "путь_к_разметке.html")]`
> Также стоит учесть, что **askama** по умолчанию все указанные файлы ищет в директории **/templates** (которая должна находиться на одном уровне с **/src**)
>
> Собственно нужно создать сам **index.html** в **/templates**:
> ```html
> <!doctype html>
> <html>
>   <head>
>     ...
>     <title>Мой крутой проект</title>
>   </head>
>   <body>
>     <h1>{{ hello_message }}</h1>
>   </body>
> </html>
> ```
